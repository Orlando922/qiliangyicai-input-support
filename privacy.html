柒量一裁输入法隐私政策

生效日期：2026 年 8 月 30 日

最后更新：2026 年 11 月 4 日

开发者主体：Runxin Xie

处理的信息

用户发起功能时，App 会处理录音、文字、个人词典、常用短语、服务设置、本机历史和用量统计。API Key 只用于连接用户选择的第三方服务。

本机保存与扩展共享

API Key 保存在 iOS Keychain。设置、词典、短语、历史、用量统计和等待中的文字结果保存在 App 沙盒或 App Group。每段录音独立保存在本机，包含成功、失败、取消或意外中断的录音，可在历史中重新转写、逐条删除或清空。录音文件不随普通设置备份导出，也不参与 iCloud 备份。普通设置备份不包含 API Key。公开发行包不携带开发者凭据、个人词典、私人短语、个人提示词、口述历史或迁移数据。

录音自动清理默认关闭，可选择 1 天、7 天、30 天或永不自动清理。用户可以在历史和隐私页主动删除本机录音及相关记录。

语音识别与文字处理

Apple Speech 由 Apple 的系统语音能力处理。用户开启第三方语音或 AI 服务后，App 会把完成当前操作所需的录音或文字发送给用户选择的服务商。服务商可能保存请求、进行安全审计或收取费用，具体规则以该服务商的隐私政策与服务条款为准。

当前语音服务支持 Apple Speech、火山豆包、阿里云百炼、OpenAI、小米 MiMo 和兼容接口。AI 服务支持火山及方舟 Coding Plan、DeepSeek、通义千问、Kimi、MiniMax、智谱 GLM、小米 MiMo、OpenAI、Claude、xAI 和兼容接口。开发者不提供代理服务器或托管模型，也不接收用户发送给这些服务商的请求内容。

键盘与“允许完全访问”

用户可先在主 App 开启可见的 PiP 浮窗，也可在主 App 关闭该浮窗。开启“允许完全访问”后，键盘通过 App Group 向主 App 发送用户主动开始或停止录音的请求；录音由主 App 执行，完成的文字结果再由键盘读取、预览或写入。键盘扩展没有麦克风访问能力，不读取或保存 API Key。后台待命录音保持关闭。

分享扩展与剪贴板

分享扩展只读取用户主动分享给 App 的文字。主 App 在用户运行剪贴板快捷指令、开启完成后自动复制或点击复制按钮时访问剪贴板。

广告、账号与跟踪

当前版本无需注册账号，不包含广告，不销售用户数据，也不进行跨 App 或网站跟踪。开发者服务器不接收本机历史、词典、录音、文字或 API Key。

保存期限与清理

本机数据会保留到用户清理或卸载 App。用户可以在“隐私”页清空 API Key、配置、个人词典、表达偏好、常用短语、历史、用量统计和等待中的结果。第三方服务的保存期限和删除方式由对应服务商规定。

未成年人

本 App 面向一般效率工具用户。未成年人应在监护人同意和指导下使用第三方语音或 AI 服务。

政策更新

数据处理方式变化后，本页会更新日期。新增开发者托管服务、账号、订阅、广告或分析 SDK 时，App Privacy 回答和隐私清单会同步更新。

联系我们

隐私咨询、数据清理或投诉可通过公开支持入口提交。请勿在反馈中填写 API Key、Access Token、录音原文或其他私人信息。
